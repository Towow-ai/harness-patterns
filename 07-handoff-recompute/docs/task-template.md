# 任务说明模板

照下面填好，整段发给子 Agent。它看不到你们的对话，
这段话就是它知道的全部。每一步怎么改不用写，路让它自己走。

## 目标
（一句话：做成以后是什么样。再一句：为什么要做。
计划和实际对不上时，它靠这一句自己判断。）

## 做好的标准
（写成能核对的句子。每个数后面跟上刚跑出它的命令，例如
"全量测试 7467 个（python3 -m pytest --collect-only -q），
改完一个都不能从通过变成失败"。改动前就失败的，逐条点名。）

## 难在哪
（你知道、它不知道的那一处：一个坑、一条约束、
一段要先读的代码，写出在哪。）

## 最容易错在哪
（你见过的错法，或者你最担心的一种。）

## 开工前先做（这一节原样保留）
把上面每个数后面的命令跑一遍。对不上，先在回报里写出来：
说明里写的是多少、你跑出来是多少、你打算按哪个做。
